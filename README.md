# Лабораторная работа №4: Файловая СУБД



## Структура проекта
- `src/db/backend/database.py` — абстрактный интерфейс базы данных.
- `src/db/backend/table.py` — бизнес-логика валидации и хранения записей конкретной таблицы.
- `src/db/backend/memory.py` — In-memory реализация СУБД.
- `src/db/backend/file.py` — Файловая реализация СУБД (сохранение в JSON).
- `src/db/backend/csv_db.py` — Файловая реализация СУБД (сохранение в CSV).

## Различия реализаций
1. **In-memory:** Данные живут только в оперативной памяти (в словарях Python) и теряются после завершения скрипта. Работает максимально быстро.
2. **Файловая (JSON/CSV):** Данные сериализуются и записываются на диск в каталог `data/`. При следующем запуске программа считывает файлы и восстанавливает состояние таблиц, обеспечивая персистентность.
