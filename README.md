#Основные изменения 
- Переход на ООП: Вся логика работы с данными перенесена в класс `StudentTable`.
-  Реализована иерархия собственных исключений (ошибки валидации возраста, дубликаты ID).
-  Проект полностью покрыт модульными тестами с использованием `pytest`.


#Структура проекта
- **src/db/backend/memory.py** — основной класс базы данных.
- **src/db/backend/errors.py** — пользовательские исключения.
- **src/db/tui.py** — консольный интерфейс.
- **tests/** — папка с автоматизированными тестами.

##Запуск проекта
python -m src.db.tui
##Запуск тестов
python -m unittest
##Оценки покрытия кода тестами :
 python -m pytest --cov=src --cov-report=term-missing
