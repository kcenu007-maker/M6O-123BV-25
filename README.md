# Прототип базы данных студентов (In-Memory)

Данный проект представляет собой реализацию легковесной базы данных, функционирующей в оперативной памяти. Проект выполнен в рамках лабораторной работы по курсу ПИОА.

 1. Структура проекта
Проект организован по модульному принципу:
src/db/backend/memory.py —  Содержит логику хранения записей в списке, а также функции для создания, чтения, обновления и удаления данных .
src/db/tui.py — Реализует текстовое меню, обработку ввода пользователя и валидацию данных.
src/db/__main__.py —  Служит для запуска приложения как модуля.
README.md — Документация проекта.

2. Реализованная функциональность
В программе реализованы следующие функции:
1. Добавление записи
2. Просмотр всех записей о студентах
3. Поиск с фильтрацией( Поиск студентов по ID, имени, фамилии, возрасту или полу.)
4. Обновление данных о студенте
5. Удаление записи о студенте
6. Обработка ошибок 

 3. Инструкция по запуску
Запускать программу через интерфейс IDE или через консоль командой:
python -m src.db
